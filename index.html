📖 Guía completa: DBC necesarios para un mapa custom

Esta guía explica paso a paso cómo editar los archivos DBC para que tu mapa personalizado y su cementerio funcionen en el cliente y en el servidor de AzerothCore.

🛠️ Herramientas necesarias

  • MyDBCEditor — para abrir, editar y guardar los archivos .dbc.
  • Noggit — editor 3D de terreno para crear el mapa (.adt, .wmo).
  • MPQ Editor — para empaquetar los DBC y el terreno en un parche .MPQ para el cliente.
  • HeidiSQL / MySQL Workbench — para ejecutar el SQL generado en acore_world.

📂 Los 4 DBC imprescindibles

Debes editar estos archivos y copiarlos tanto en el servidor (carpeta data/dbc) como en el cliente (dentro de un parche MPQ).

1️⃣ Map.dbc (registro del mapa)

  • Columna 1 (ID): el ID de tu mapa. Debe ser único y coincidir con el Map ID que usas en el generador.
  • Columna 2 (InternalName): nombre interno, por ejemplo MiMapaCustom.
  • Columna 4 (Type): tipo de mapa (0 = mundo abierto, 1 = dungeon, 2 = raid, etc.).
  • Columna 23 (AreaTableID): aquí pondrás el Area ID que crees en el AreaTable.dbc.

2️⃣ AreaTable.dbc (la zona del mapa)

  • Columna 1 (ID): el Area ID único de tu zona. Este valor es el GhostZone que usas en el generador.
  • Columna 2 (MapID): el ID de tu mapa, el mismo de la columna 1 del Map.dbc.
  • Columna 5 (Flags): aquí defines el comportamiento de la zona. Los valores más útiles son:
    • 0x00000040 → AREA_FLAG_ALLOW_DUELS (permite duelos).
    • 0x00000800 → AREA_FLAG_SANCTUARY (santuario, PvP desactivado).
  • Columnas 12-28: aquí escribes el nombre visible de la zona, por ejemplo Mi Zona Custom.

3️⃣ WorldSafeLocs.dbc (el cementerio)

  • Columna 1 (ID): el Graveyard ID. Debe ser único y coincidir con el que pones en el generador.
  • Columna 2 (MapID): el ID de tu mapa, el mismo de Map.dbc.
  • Columnas 3, 4 y 5 (X, Y, Z): las coordenadas donde reaparecerá el fantasma. Puedes obtenerlas dentro del juego con el comando .gps.
  • Columna 7: el nombre del cementerio, por ejemplo Cementerio Mapa Custom.

4️⃣ MapDifficulty.dbc (evita crashes en grupo)

  • Añade una nueva fila con tu Map ID en la segunda columna. Si no lo haces, invitar a otro jugador al mapa puede tirar el servidor.

✅ Orden correcto de los pasos

  1. Edita AreaTable.dbc y crea tu zona (ID y nombre).
  2. Edita Map.dbc y en la columna 23 pon el Area ID que acabas de crear.
  3. Edita MapDifficulty.dbc y añade tu Map ID.
  4. Edita WorldSafeLocs.dbc y crea el cementerio con el Graveyard ID y el Map ID correctos.
  5. Empaqueta los DBC editados en un parche .MPQ para el cliente y cópialos también en la carpeta data/dbc del servidor.
  6. Usa esta página para generar el SQL y ejecutarlo en acore_world.
  7. Entra al juego, ve a tu mapa y ejecuta .linkgrave TuGraveyardID para vincular el cementerio.
  8. No olvides spawnear un Spirit Healer (ID 6491) en el cementerio para que los jugadores puedan resucitar.
⚠️ Importante: si tu cementerio no funciona, revisa que hayas extraído los maps del cliente y que el AreaTable.dbc del servidor también esté actualizado.
